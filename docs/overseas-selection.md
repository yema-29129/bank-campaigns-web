# 海外优惠筛选规则

适用于羊毛助手 Pro 网站的「海外优惠」专题。按实际消费场景决定是否进菜单，按发卡、账户或居住地区判断谁可以参加。这两个字段分别记录。分类只控制网页展示。

## 收录条件

1. 对香港本地消费、跨境购物或出境旅行有实际用途，能说明具体优惠金额、折扣、回赠、积分、费用减免或明确权益。
2. 回到主办方、发行银行、卡组织或商户的当期官方规则核验。自媒体、截图及群消息只用于发现线索。生成器会检查已发布记录的来源链接格式，编辑仍须核实链接主体、条款及当前状态。
3. 参与者资格、消费地点或平台站点、使用方式、门槛、币种及开始和截止日期明确。区分报名、领券、下单、出发或入住日期，保留封顶、名额、手续费和退款条件。规则不清楚或已提前下线的活动暂停展示，等补证。
4. 常驻列表展示当前有效的活动。未开始的保留原详情供需要的人查看，已结束的保留历史记录。黑五和网一专属活动归到季节专题。单纯新闻、购物清单、一般开户介绍和没有具体优惠的常青攻略可另作文章。
5. 以主办方、核心优惠、适用资格、地区、周期和入口查重。优先更新原活动和使用已有详情网址。多个使用场景时选择用户领取后主要会做的那件事，例如网上订酒店仍归订房，香港发卡的日本消费回赠归境外用卡。仅限内地日常使用的活动归原分类。
6. 同类优先普通用户可参加、步骤少、门槛低和优惠确定的活动。受邀、新客、随机或付费条件须写明。精选每个二级分类最多展示六条，同一优先级沿用网站活动目录的顺序，提供现有专题入口供继续查询。

## 二级分类

| 一级 | 二级 | 判定例子 |
| --- | --- | --- |
| 香港本地優惠 | 餐飲與茶飲、超市與本地購物、八達通／交通與繳費、港卡與電子錢包 | 香港餐厅满减归餐饮，惠康门市和网店的香港活动归本地购物，八达通增值归交通缴费。只有香港发卡条件、实际在海外使用的活动按海外场景走。 |
| 海淘购物 | 跨境电商与平台优惠、外币网购回赠、跨境配送与转运 | 面向香港用户的淘宝优惠归跨境平台，明确计入非港币网上签账的回赠归外币网购。香港本地网店的日常活动归本地购物。 |
| 出境旅行 | 机票与里程、酒店与订房、景点与当地交通、eSIM 与境外上网、境外刷卡／支付与取现 | 机酒套餐按机票与里程归一处，酒店、租车、景点门票各按用途归类。只有官网注明境外使用的流量优惠才归境外上网。 |

网页只渲染有合格活动的二级分类。活动复核通过后随网页目录重新生成，只有编辑再次核验才能更新规则或有效期。eSIM、境外流量卡及网络工具按独立网页发布规则标记为 `web_only`。VPS、域名等与消费者海外优惠场景无关的内容留在相应网页专题。网站发布时只修改独立网站仓库。
